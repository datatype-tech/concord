# 动画混合与状态机

`engine/animation` 在单 clip 采样（[资源与骨骼动画.md](资源与骨骼动画.md)）之上
提供完整的混合栈：pose 混合、状态机过渡、骨骼遮罩与动画层。所有混合最终都收敛到
同一个 `SkinningPoseComponent`，因此渲染侧（快照、palette 上传、蒙皮管线）完全
不需要感知混合的存在。

## 分层结构

```text
AnimationGraph（不可变描述：状态 + 转移）
        │
AnimationStateMachineState（运行时：当前/目标状态、过渡权重）
        │   EvaluateAnimationStateMachine()
        ▼
SkeletonPose（基础姿势）
        │   AnimationLayer × N（Override / Additive + JointMask）
        ▼
SkinningPoseComponent（唯一渲染输出）
```

组件保存数据，行为全部在自由函数与 `AnimationSystem` 中——与"组件是纯聚合体"
的工程规范一致。

## Pose 混合

```cpp
Concord::SkeletonPose blended;
Concord::BlendPoses(skeleton, poseA, poseB, 0.5f, blended);   // crossfade
Concord::AdditiveBlendPose(skeleton, base, additive, 1.0f, out); // 加法
```

- 平移/缩放线性插值，旋转走四元数 Slerp（最短路径）。
- 权重夹取到 [0, 1]，NaN 视为 0。
- 某关节缺失时回退到该骨架的绑定姿势。
- 加法混合以绑定姿势为参考：平移/缩放叠加增量，旋转乘以相对增量。

## 状态机

`AnimationGraph` 描述状态与转移，构建后不可变，可被任意多个实例共享：

```cpp
Concord::AnimationGraph graph;
graph.states.push_back({.name = "walk", .clipIndex = walkClip});
graph.states.push_back({.name = "run", .clipIndex = runClip});
graph.transitions.push_back({.fromState = 0, .toState = 1,
                             .duration = 0.25f, .hasExitTime = true, .exitTime = 1.0f});
graph.initialState = 0;
```

运行时状态保存在 `AnimationStateMachineState`（不是组件成员函数）：

```cpp
Concord::AnimationStateMachineState runtime;
Concord::EvaluateAnimationStateMachine(asset, graph, skeletonIndex, dt, runtime, pose);
Concord::RequestAnimationTransition(graph, std::string_view{"run"}, runtime);
```

求值规则：

1. 首次求值从 `graph.initialState` 起步；非法图（未知 clip、重复状态名、
   非法转移参数）直接失败，不产生姿势。
2. 每帧推进当前状态时钟；循环状态按 clip 时长回绕，非循环状态到端点后
   置 `finished`。
3. `RequestAnimationTransition()` 请求的切换在当帧生效，但必须存在对应的
   有向转移，否则被忽略。
4. `hasExitTime` 的转移在归一化播放进度越过 `exitTime` 时自动触发。
5. 过渡期内同时采样两个 clip，按 `transitionTime / duration` 权重混合；
   `duration = 0` 表示立即切换。过渡可被 `canInterrupt` 允许的新目标打断。

## 骨骼遮罩与动画层

```cpp
Concord::JointMask upperBody = Concord::MaskSubtree(skeleton, spineJoint);
layer.mask = upperBody;          // 空权重向量表示"全部关节"
layer.mode = Concord::AnimationBlendMode::Override;  // 或 Additive
layer.weight = 0.8f;
layer.graph = &aimGraph;         // 层有自己独立的图与运行时状态
layer.enabled = true;
```

- `MaskSubtree()` 取一个关节及其全部后代；`MaskJoints()` 按关节名精确匹配；
  逐关节权重支持 0~1 羽化。
- 层按数组顺序求值：先基础图，再依序叠加各层；Override 层按权重与遮罩
  覆盖关节，Additive 层在遮罩关节上叠加相对绑定姿势的增量。
- 每个实体最多 `kMaxAnimationLayers = 4` 个层，层数据定长，评估期无堆分配。

## ECS 接入

```cpp
entity.Add<Concord::AnimationControllerComponent>({...})
      .Add<Concord::SkinningPoseComponent>({});
```

`AnimationSystem` 对同时带有旧 `AnimationComponent` 与 controller 的实体只走
controller 路径；旧单 clip API 保持原语义，两条路径输出同一份
`SkinningPoseComponent`。

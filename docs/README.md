# Concord Flash 文档

本目录记录 Concord Flash 的语法设计与架构决策，按主题分文件、随引擎同步维护。
工程规范（命名、文件布局、提交要求）见仓库根目录的 `AGENTS.md`；这里只谈"怎么用、为什么这样设计"。

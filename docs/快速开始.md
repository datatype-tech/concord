# 快速开始

## 最小示例

```cpp
#include <Concord/CApplication.h>
#include <Concord/CObject.h>
#include <Concord/CScene.h>

int main()
{
    Concord::Game game;
    Concord::Window window({.title = "My Game", .resolution = {1280, 720}});
    game.AttachWindow(window);

    Concord::Scene scene;
    scene.Spawn<Concord::Object::Camera>({.position = {0.0f, 2.0f, -5.0f}});
    scene.Spawn<Concord::Object::Box>({.transform = {.position = {0.0f, 1.0f, 0.0f}}});

    game.LoadScene(scene);
    game.Run();
}
```

## 构建

```sh
cmake -S . -B build -G Ninja -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++
cmake --build build
./build/main.exe
```

首次构建前先运行一次 `setup_deps.ps1`，把 SDL3/Vulkan/Steam Audio/stb 装进
`concord/src/3rd` 和 `concord/lib`（见[构建与依赖.md](构建与依赖.md)）。

## 打包成可分发的 bin/

```sh
./package_bin.ps1
```

产出 `bin/`：可执行文件、两个引擎 DLL（`ConcordFlashGameEngineRuntime.dll`、
`ConcordFlashGameEngineRender.dll`）、第三方运行时 DLL、MinGW 运行时，
以及供运行期写入的 `Assets/Config/Data/Logs/Scenes` 目录。

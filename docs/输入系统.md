# 输入系统

引擎的输入基础设施分两层：**原始层**（`Window` 上的键盘/鼠标三态查询与
`InputSnapshot`）和**动作层**（`InputMap`，把游戏语义绑定到原始输入，支持
运行时重绑定）。SDL 细节完全隔离在 Runtime 内部，公开头不携带任何
`SDL3/SDL.h`。

## 原始层：三态快照

`Window::Input()` 返回 `const InputSnapshot&`，包含事件泵本帧收集的全部
原始输入：

| 成员 | 内容 |
|---|---|
| `keys` / `mouseButtons` | 每键/每钮的 `Down`/`Pressed`/`Released` 位标志 |
| `mousePosition` | 光标的窗口客户区坐标 |
| `mouseDelta` | 相对移动增量（仅光标捕获时累计） |
| `wheelDelta` | 滚轮增量（y 正为上滚，自动处理 flipped 方向） |

三态语义：

- `Down`：本帧物理按住。
- `Pressed`：从释放到按住的那个泵置位，只存在一帧。
- `Released`：从按住到释放的那个泵置位，只存在一帧。
- SDL 的 key repeat 不会重复触发 `Pressed`。
- 窗口失焦时所有按住中的键/钮补发 `Released` 并清空增量。

也可以直接用 `Window` 的便捷查询：`IsKeyDown / WasKeyPressed /
WasKeyReleased(KeyCode)`、`IsMouseButtonDown / WasMouseButtonPressed /
WasMouseButtonReleased(MouseButton)`、`MousePosition / MouseDelta /
MouseWheelDelta`。

`KeyCode` 是平台无关的物理键码表（美式布局位置，与字符和输入法无关），
覆盖字母、数字、F1–F12、方向键、左右修饰键、标点与小键盘。

## 动作层：InputMap 与运行时重绑定

游戏代码不应散落硬编码键位，而是定义动作（调用方自己的 `enum` 转 `u32`），
把动作绑定到键或鼠标键：

```cpp
enum GameAction : Concord::u32 { MoveForward = 1, Jump, Fire };

Concord::InputMap input;
input.BindKey(MoveForward, Concord::KeyCode::W);
input.BindKey(MoveForward, Concord::KeyCode::Up);      // 多绑定按 OR 求值
input.BindMouseButton(Fire, Concord::MouseButton::Left);

// 每帧：用本帧快照求值，然后查询动作级三态
input.Update(window.Input());
if (input.WasPressed(Jump)) { /* ... */ }
if (input.IsDown(MoveForward)) { /* ... */ }
```

边缘语义是**动作级**的：`WasPressed` 表示动作整体从释放进入按下——无论
是哪一条绑定引起的；一条绑定按住时另一条新按下不会误报 Pressed，一条
释放而另一条仍按住也不会误报 Released。

重绑定在任意两次 `Update` 之间进行：

```cpp
// 设置界面中把"跳跃"从空格改到右 Shift：
input.UnbindKey(Jump, Concord::KeyCode::Space);
input.BindKey(Jump, Concord::KeyCode::RightShift);
```

解绑动作的全部绑定时，动作状态会保留一帧以产生正确的释放沿，之后自动
清隐；`ClearAction`/`Clear` 则立即丢弃状态。

## 第一人称控制器

`FirstPersonController` 是动作层的首个消费者：`Settings` 暴露全部键位
（`forward/backward/left/right/flyUp/flyDown/sprint` 与
`captureButton`），构造时写入内部 `InputMap`；`Actions()` 返回该映射的
引用，可在运行时直接重绑定控制器：

```cpp
auto& actions = controller.Actions();
actions.UnbindKey(static_cast<Concord::u32>(Concord::ControllerAction::Sprint),
                  Concord::KeyCode::LeftShift);
actions.BindKey(static_cast<Concord::u32>(Concord::ControllerAction::Sprint),
                Concord::KeyCode::RightShift);
```

## 手柄

SDL Gamepad 支持（连接事件、按钮三态、摇杆/扳机轴与动作轴绑定）规划为
下一个输入切片；`InputSnapshot` 为其预留了扩展位，动作层的绑定结构届时
直接增加轴设备类型。
